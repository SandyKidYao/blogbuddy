The document stays the main thing.

Chat tools make you leave the page. BlogBuddy keeps the page and hangs the conversation off it.

A chat pane

Copy the text over. Explain the context. Wait. Carry the useful part back. Lose your place.

Margin notes

⌘B ⌘B, one sentence, ↵. The caret is back where you were. The answer lands quietly under the block.

Quiet by design.

Notes never touch your Markdown file. Changes come back as proposals you accept block by block.

Background

Marching dashes while the agent works. When it lands, only one line changes. Nothing pops up and the caret never moves.

Proposals, not edits

The agent returns a rewrite; you see the diff per block. Accepting is an ordinary edit, so ⌘Z undoes it.

Read-only agent

It can read your workspace and search the web. It cannot write files or run commands that change anything.

Signs, not words.

The interface speaks in Markdown's own glyphs, so it stays out of your way.

A live-preview editor underneath.

Live preview

Frontmatter head

Title, date, tags and more edited in place, with raw YAML one click away.

Zen mode

A centered column whose chrome fades while you type.

Slash menu

Block types, written as Markdown.

IME-safe

CJK composition reaches the document only once committed.

Paste to disk

Dropped images are saved beside the document and linked by relative path.

Four steps.

  1. Install BlogBuddy from the VS Code Marketplace.
  2. Have Claude Code or Codex installed and signed in. No API key to configure.
  3. Open a .md and press ⌘⇧B to open BB Editor.
  4. Press ⌘B ⌘B in a paragraph, ask, and keep writing.
